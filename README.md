# Undertale Web — Fan Game

An unofficial, browser-based Undertale-style fan-game project built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build tools, libraries, or external services are required.

## Controls

- Move: Arrow keys or WASD
- Confirm / interact: Z or Enter
- Cancel / back: X or Escape
- Battle: Arrow keys to navigate and move the SOUL

## Current playable foundation

- Pixelated 320×240 canvas, scaled cleanly for modern screens
- Original placeholder pixel-art characters and environments
- Three connected Ruins rooms with walls, doorways, signs, a save point, and a chest
- Keyboard movement with collision detection
- Dialogue and interaction system
- HP, LV, gold, and inventory
- Local browser save data
- First turn-based battle prototype with FIGHT, ACT, ITEM, MERCY, a timing meter, and a SOUL-dodging phase

## Development roadmap

1. Expand the Ruins into a complete, polished opening chapter
2. Improve character animation, room art, puzzles, and sound
3. Expand battle patterns, enemy behavior, items, and progression
4. Build the remaining regions and story systems incrementally
5. Add mobile controls after the keyboard experience is solid
