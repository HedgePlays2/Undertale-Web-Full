# Undertale Web — Fan Game Prototype

A browser-based Undertale-inspired fan-game project built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Controls
- Move: Arrow keys or WASD
- Interact / advance dialogue: Z or Enter
- Walk to the glowing star in the lower-left corner to save

## Current foundation
- Pixelated 320×240 canvas presentation, scaled for modern screens
- Basic top-down exploration
- Two connected placeholder areas
- Dialogue and interaction
- HP, LV, gold, inventory data
- Browser localStorage save
